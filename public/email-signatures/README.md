# Ysabel Society email signature archive

This folder is the approved archive for reusable email signatures.
Keep each person's final HTML, copy page, contact details and source images.
For future Ysabel email signatures, add a person folder here and retain prior approved signatures.
Keep the archive unlinked from the main website navigation. Pages request no indexing;
the files remain publicly reachable and must never contain secrets.
